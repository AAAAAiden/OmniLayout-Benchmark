# Dataset licensing and provenance

The software license in `LICENSE` applies to the project code. It does not
relicense the PCB designs or the processed graph dataset.

The graph files were derived from third-party EAGLE PCB designs. A complete,
per-design mapping of source URLs, copyright holders, applicable licenses, and
required attribution has not yet been supplied with this release. Original
design names are retained in the graph filenames for identification.

No blanket dataset license is asserted here. Public availability of these files
should not be read as a grant of rights beyond the permissions available from
the relevant rights holders. Consult the upstream design's terms before reuse
or redistribution. A future release should add verified per-design provenance
and the applicable attribution and license notices.

Only processed graph JSON is distributed. Original `.brd` and `.sch` files are
excluded. The dataset archive contains this notice independently of the code.
